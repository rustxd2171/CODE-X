🌐 Introduction to HTML, CSS, and JavaScript 🚀

📌 What is HTML?

HTML (HyperText Markup Language) is the foundation of web development. It structures web pages using elements like headings, paragraphs, links, and images.

🎨 What is CSS?

CSS (Cascading Style Sheets) is used to style and enhance web pages. It controls colors, fonts, layouts, and animations, making websites visually appealing.

⚡ What is JavaScript?

JavaScript is a powerful programming language that adds interactivity to websites. It enables dynamic content, animations, and user interactions.
